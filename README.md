This is a quick and dirty repository for the research code used to produce the results in the conference paper: New Sizing Rules and Algorithims for Unmanned Lunar Landers, Conall de Paor, 2025, 11th EUCASS Conference.
To recreate the results of this conference paper, use the functions in validation.py. 
To see the definitive versions of the lunar lander databases, see: lander DB 251redux (alt).xlsx and subsystems database.xlsx The sources of the numbers in the database are detailed in the paper. 
The delta V and the Isp columns are estimations based based in the recorded mission of the spacecraft and on the stated fuel type.
If you plan to use this database in your work, cite the conference paper mentioned above.
